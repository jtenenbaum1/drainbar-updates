# DrainBar 0.3.2

Notifications are more complete, configurable, and reliable.

- Added Claude 5-hour and weekly reset notifications.
- Added OpenAI 5-hour reset notifications when that window is available, plus weekly reset notifications.
- Added support for multiple custom usage alerts with user-selected percentages.
- Fixed notification permission status so it reflects the current macOS setting.
- Notifications can now present banners, appear in Notification Center, and play a sound while DrainBar is active.
- Fixed false session-reset alerts caused by one-second reset-time fluctuations.
- Added a setting to disable yellow and red service-incident tinting on menu-bar provider icons.
