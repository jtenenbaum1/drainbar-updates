# DrainBar 0.3.5

Updates are easier to notice from the usage popover.

- A small blue download icon appears beside Settings when an update is available. Click it to open the signed-update window.
- Automatic update checks now run about once an hour. Your automatic-check and automatic-download preferences are preserved.
- Ordinary scheduled updates use the quiet footer reminder. Critical updates retain Sparkle's prominent presentation.
- Successful local releases notify the running app to check its signed update feed again. Repeated signals are coalesced and active update sessions are respected.

Includes the Claude credential resilience improvements and Sparkle 2.9.6 security fixes from 0.3.4.
